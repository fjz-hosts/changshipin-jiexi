Android 版

下载 APK 直接安装。首次安装如果系统提示「未知来源」，允许一次即可；后续版本覆盖安装，配置和历史都会保留。

如果某个镜像打不开，换下面任意一个；安装包在所有镜像上是同一个文件。

iOS 免签名版（IPA）

iOS 不能像 Android 那样直接安装 IPA。免签名 IPA 需要用电脑上的 Sideloadly 或 AltStore 用自己的 Apple ID 重新签名后安装； 适合没有越狱、能接受 7 天 / 1 年有效期的用户。

下载 iOS IPA
  1. 电脑安装 Sideloadly（或 AltStore），iPhone 用数据线连接电脑。
  2. 把下载的 IPA 拖进 Sideloadly，输入自己的 Apple ID，点 Start。
  3. 手机上到「设置 → 通用 → VPN 与设备管理」信任开发者。
  4. 到期后重新拖一次 IPA 即可，应用内配置和历史会保留。

电脑端

电脑端是 Windows 安装包，和手机端同一次发布、同一版本号。电脑端内置「手机版」二维码，手机扫码即可下载。
