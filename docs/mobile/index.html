Android 版

下载 APK 后按下面步骤装到手机；首次安装需要允许「未知来源」。后续版本覆盖安装，配置和历史都会保留。

下载 Android APK
  1. 点上面的按钮下载 changshipin-android.apk。
  2. 下载完成后，下拉通知栏点「下载完成」，或打开「文件管理 → 下载 / Download」。
  3. 第一次点 APK 会提示「禁止安装未知应用」：点「设置」→ 允许当前浏览器 / 文件管理器 → 返回继续。
  4. 点「安装」，完成后在桌面打开「长视频解析」。
  5. 以后升级直接下载新 APK 覆盖安装，不用卸载。

如果某个镜像打不开，换下面任意一个；安装包在所有镜像上是同一个文件。提示「解析包错误」时删掉旧 APK 重新下载。

iOS 免签名版（IPA）

iOS 不能像 Android 那样直接安装 IPA。免签名 IPA 需要用电脑上的 Sideloadly 或 AltStore 用自己的 Apple ID 重新签名后安装； 适合没有越狱、能接受 7 天 / 1 年有效期的用户。

下载 iOS IPA
  1. 点上面的按钮下载 changshipin-ios-unsigned.ipa；Safari 会存到「文件」App → 下载。
  2. 电脑安装 Sideloadly（或 AltStore），iPhone 用数据线连接电脑并点「信任」。
  3. 把下载的 IPA 拖进 Sideloadly，输入自己的 Apple ID（普通账号即可），点 Start。
  4. 手机上到「设置 → 通用 → VPN 与设备管理」信任开发者证书。
  5. iOS 16 及以上打开「设置 → 隐私与安全性 → 开发者模式」，重启手机一次。
  6. 回桌面打开应用。个人 Apple ID 签名 7 天有效，到期重复第 3 步覆盖安装，配置和历史保留。

免签名 IPA 不含任何证书；Apple ID 只在本机验证，不会上传到本项目。

为什么 iOS 不能像 Android 一样直接装？有没有更省事的办法？

Android 允许自签名 APK + 未知来源；iOS 只运行 Apple 信任证书签名的 App，免签名 IPA 没有证书，系统安装器会直接拒绝。这是 iOS 的机制，不是本程序能绕过的。

更省事的选择：

  • TrollStore：部分 iOS 14.0–17.0 设备支持，装上后永久使用、不用续签；先看 官方兼容表。
  • AltStore + AltServer：首次用电脑，之后同一 Wi-Fi 下自动续签，7 天一次不用反复插线（altstore.io）。
  • SideStore：配置一次后可在手机上续签，不用一直开电脑（sidestore.io）。
  • Apple Developer Program：$99/年，签名 1 年；首次仍需电脑安装。

没有「免费 + 永久 + 完全不用电脑」的通用办法。PWA 网页版虽然免安装，但拿不到本地取流代理、下载、内置浏览器等完整能力，不能替代手机 App。

电脑端

电脑端是 Windows 安装包，和手机端同一次发布、同一版本号。电脑端内置「手机版」二维码，手机扫码即可下载。
