视频解析 · 使用说明
========================================

一、这是什么
  程序分「长视频」和「短视频」两个模式：
  - 长视频：把爱奇艺、腾讯视频、优酷、芒果TV 的视频页链接粘贴进来，
    选一条解析线路，就能在程序里直接播放；
  - 短视频：抖音、B站、AcFun、红果短剧、快手的链接解析后，可选清晰度
    下载 MP4；短剧 / 合集可以一键下载全集并自动创建剧名文件夹。

  程序本身不提供、不存储任何视频内容。长视频解析由互联网上公开的
  第三方接口完成，线路可能随时失效，换一条或自己添加即可。


二、安装
  1. 运行 changshipin-Setup-<版本>.exe，按提示安装；
  2. 程序未做代码签名，SmartScreen 提示时点「更多信息 → 仍要运行」；
  3. 安装完成后桌面/开始菜单会出现「视频解析」。


三、四个平台快捷入口
  顶部四个卡片使用各平台官方 App 图标：爱奇艺、腾讯视频、优酷、芒果TV。
  - 点卡片：平台网页直接在主窗口内打开，不再另开窗口；
    上方有后退 / 前进 / 刷新 / 首页 / 地址栏，点「返回首页」回到播放界面；
  - 打开过的平台会出现在网页上方的标签栏里，点标签切换、点 × 关闭；
  - 卡片右上角「↗」：用系统默认浏览器打开官网；
  - 在内置浏览器里点开任意剧集后，程序会自动把「具体某一集」
    送到主界面解析播放（工具栏「自动解析」默认开启，每个平台单独记忆）；
  - 也可以点「解析本集」手动送入主界面，或点「复制本集」复制当前剧集链接；
  - 在首页/搜索页点「复制本集」会提示「请先点开具体某一集」，
    这是为了避免复制成首页链接。


四、找剧（聚合搜索）
  1. 点右上角「找剧」；
  2. 输入剧名，勾选一个或多个平台；
  3. 点「聚合搜索」，程序会在后台同时打开各平台搜索页并抓取结果，
     直接把结果列在窗口里，不打断当前播放；
  4. 点「单集」结果会直接解析播放；点「剧集页」结果会打开内置浏览器选集页；
  5. 平台要求验证码 / 登录、或没有抓到结果时，点该平台右侧「打开平台页」，
     回到原来的搜索页流程手动找。

  外站播放链接（比如爱奇艺搜索页里的「腾讯 外站付费播放」）会自动
  切换到对应平台的内置窗口；其他站点也会用带工具栏的内置窗口打开。


五、解析播放
  1. 把链接粘贴到输入框（支持直接粘贴分享文案，会自动提取链接）；
  2. 选一条线路（默认自动选上次成功的线路）；
  3. 点「解析播放」或按 Enter；
  4. 解析页加载完成后即可播放。

  链接示例：
    爱奇艺    https://www.iqiyi.com/v_b13ju3xx7s.html?lt=2
    腾讯视频  https://v.qq.com/x/cover/mzc002001w361jz/x4102olnagg.html
    优酷      https://v.youku.com/v_show/id_XNjU3MzkyOTA0NA==.html
    芒果TV    https://www.mgtv.com/b/817372/24769759.html


六、选集（播放器下方）
  解析成功后，视频下面会出现整部剧的选集条：
  - 点任意一集直接切换，视频下面会高亮当前集；
  - 「上一集 / 下一集」：也可以按 [ / ] 或 Ctrl+← / Ctrl+→；
  - 「倒序」切换正序/倒序；「收起」把选集条折叠起来；
  - 勾选「自动连播」：本集播完后自动播放下一集；
  - 选集是自动从平台取的：芒果/腾讯/优酷/爱奇艺都支持，取不到时可以
    点平台卡片回到网页里手动点集（会自动解析）；
  - 视频按 16:9 显示；播放时整页可以上下滚，顶部的平台入口/链接栏会跟着滚走，不会挡住视频；
  - 选集列表会记住，下次从「观看历史」点回来也能直接换集；
  - 内置播放器和网页解析线路都会记录观看进度；两种播放器都支持播完自动下一集。


七、解析失败怎么办
  - 点「换线路」：用下一条线路重新解析；
  - 设置里打开「解析失败自动切换下一条线路」后，程序会按线路
    列表顺序自动重试；体检标记为失效的线路会排在最后；
  - 点侧栏「测速」，看哪些线路当前可访问（测速通过不代表一定能播）；
  - 线路全部失效时，用「官网页面（会员登录）」线路：直接打开原片
    页面，登录会员账号后观看，不经过第三方解析；
  - 芒果TV：默认会先走「芒果TV 原生解析」线路（国内客户端参数直连）。
    如果仍提示地区限制，说明芒果按当前公网 IP 做了版权限制；VIP 内容请
    先在芒果内置窗口登录会员，再回到主界面解析，原生线路会自动带上登录 Cookie。
  - 腾讯视频：默认仍走 789 等第三方线路；第三方线路都失败后才会用
    「腾讯视频 原生解析」作为备用（按 yt-dlp 的官方接口流程）。电影 / 电视剧 /
    动漫 / 纪录片都适用，免费内容一般 720P；付费 / 云影院内容通常只给试听。
  - 爱奇艺 / 优酷：yt-dlp 当前解析不了这两家的新版播放页，仍从 789 等第三方
    线路开始；原生解析线路默认关闭，别手动打开（打开了也会提示原因并换线）。


八、线路管理（设置 → 解析线路）
  - 侧栏里灰色的是「未启用」，点一下即可启用（启用后出现在下拉框里）；
  - 每条线路可以启用/停用、改名、改地址、删除；
  - 类型：
      网页：地址形如 https://jx.example.com/?url={url}
            程序在内置浏览器里打开解析页，由解析页播放；
      接口：程序请求 {url} 接口，从返回的 JSON/HTML 里自动提取
            m3u8/mp4 地址，再用内置播放器播放；
      直连：不解析，直接打开原视频页面（适合已登录会员）；
      芒果内置：直接调用芒果TV 官方取流接口，仅用于芒果TV，
            国内网络下优先使用，登录芒果会员后可解 VIP；
      原生解析：主进程直接调用平台官方接口（腾讯视频按 yt-dlp 的
            getvinfo 流程；芒果TV 走芒果内置接口）。腾讯默认开启但只作备用，
            第三方线路都失败后才尝试；爱奇艺 / 优酷当前不可用，线路默认关闭。
  - 「在线更新线路」：从 GitHub 上项目的 lines.json 拉取最新
    内置线路（不会覆盖你自建的线路）；
  - 「恢复内置线路」：回到随程序发布时的默认线路；
  - 「清理失效线路」：删除最近一次体检失败的线路；
  - 侧栏「隐藏失效」：把体检失败的线路从列表里藏起来；
  - 建议只保留自己验证过能用的线路，并把它排在最前面。


九、下载
  - 内置播放器播放时，播放区上方有「下载」按钮；点一下开始下载，
    按钮上显示进度，再点一次取消；
  - HLS（m3u8）会把分片逐个下载、解密（AES-128）并合并成一个
    .ts / .mp4 文件，不需要 ffmpeg；mp4 直接保存；
  - 保存位置优先是程序安装目录旁的「视频解析下载」文件夹
    （装到 D 盘就不会占系统盘，更新 / 卸载也不会删掉里面的视频）；
    安装位置不可写或系统拦截写入时，会自动改用系统下载目录 /
    配置目录下的 downloads；
  - 可以点「设置 → 播放 → 打开下载目录」查看文件；
  - 第三方网页解析线路（page）拿不到真实流地址，不支持下载；
  - DRM / SAMPLE-AES 加密的会员内容不支持下载。


十、全屏
  点播放区右上角「全屏」（或按 F11）：窗口会铺满整个电脑屏幕，
  并隐藏顶部工具栏与侧栏，只留播放画面和一条悬停才显示的控制条。
  全屏后：空格暂停/播放，←/→ 快退/快进 10 秒，↑/↓ 音量，M 静音；
  按 Esc 或再点「退出全屏」恢复原样。内置播放器和网页解析线路都支持这些快捷键。


十一、自动更新
  程序启动约 6 秒后自动检查更新，之后每 4 小时一次；
  发现新版本会后台静默下载；下载完成后提示一次「立即重启安装」，
  点它之后会在后台静默覆盖安装，不会弹出安装向导的下一步/目录选择，
  原有配置、登录状态和桌面快捷方式都会保留，装完自动打开新版本。
  更新包放在 GitHub Releases，程序内置多个国内加速源自动切换。
  也可以在「设置 → 更新」里手动检查。


十二、数据与日志
  - 配置 / 解析记录：%APPDATA%\视频解析\config.json
  - 日志：%APPDATA%\视频解析\logs\desktop.log
  - 下载目录：优先程序安装目录旁的「视频解析下载」，回退系统下载目录 / %APPDATA%\视频解析\downloads
  - 从旧版「长视频解析」升级时，首次启动会自动迁移原配置与历史
  - 菜单「文件」里可以一键打开配置/日志目录；
  - 卸载程序不会删除配置；需要彻底清理时手动删除上述目录。


十三、快捷键
  Enter            解析当前链接
  F11              全屏 / 退出全屏
  Esc              退出全屏 / 关闭设置窗口；在内置浏览器里返回播放界面
  F5               刷新画面；内置浏览器打开时刷新网页
  Ctrl+Shift+V     粘贴剪贴板链接并解析
  Ctrl+Shift+N     换线路
  空格             暂停 / 播放（全屏时同样可用）
  ← / →            快退 / 快进 10 秒
  ↑ / ↓            音量
  M                静音
  Ctrl+← / Ctrl+→  选集：上一集 / 下一集（[ / ] 同样可用）
  Alt+← / Alt+→    内置浏览器里后退 / 前进
  Ctrl+W           关闭当前浏览器标签


十四、免责声明
  本程序仅用于学习与个人合法观看。解析线路由第三方提供，其内容、
  可用性与合法性由提供方负责。请遵守各视频平台的用户协议和当地
  法律法规，不要用于传播盗版内容或商业用途。


十五、快捷方式丢了怎么办
  安装/更新后如果桌面快捷方式不见了：
  - 菜单「文件 → 重新创建桌面快捷方式」；
  - 或打开「设置 → 关于」，点「重建桌面快捷方式」；
  - 也可以直接重新运行安装包，选择原来的安装目录覆盖安装。


十六、观看历史
  主界面右侧「观看历史」按作品记录：
  - 同一部剧只保留一条，记「最近看到第几集 + 这一集的进度」；
    之前看完的集数不再重复占位置，看下一集会更新同一条记录；
  - 显示剧名、集数（如「第5集」）、平台、线路、观看时间和进度条；
  - 点一下会打开最近那一集，并从上次位置继续播放；
  - 顶部搜索框可以按剧名/集数/平台过滤；
  - 右上角下拉可以切「最近 / 继续观看 / 按平台」；
  - 鼠标移到记录上点「×」删除整部剧的记录，点「清空」删除全部；
  - 旧版本一集一条的记录和只存网址的记录，升级后会自动合并 / 补标题。


十七、图文教程
  点右上角「使用教程」打开应用内图文教程；播放区为空时也可以点
  「第一次用？打开图文教程」。左侧是章节，右侧是截图和说明：
  图里的红框就是这一步的重点，按 Esc 或点右上角关闭。


十八、短视频 / 短剧下载（1.2.0 新增）
  1. 顶部把「长视频」切到「短视频」，进入独立的短视频界面；
  2. 支持抖音、B站、AcFun、红果短剧、快手；分享短链可以直接粘贴，
     例如 v.douyin.com/xxx、b23.tv/xxx、v.kuaishou.com/xxx；
  3. 点「解析视频」，视频在左侧大画面播放，标题、作者和清晰度在视频下方；
  4. 选清晰度后点「下载 MP4」，进度显示在右侧「下载队列」；
  5. 短剧 / 合集会在下方列出分集：
     - 点「全选」或逐集勾选；
     - 点「一键下载全集」，程序会自动创建「剧名」文件夹，
       所有分集按集数命名保存；
     - 抖音支持合集 / 短剧链接（douyin.com/collection/xxx 或 /mix/detail/xxx），
       单个视频属于某个合集时会自动展开整部剧；「下载本集」仍只下当前这一集。
       抖音下载遇到 431（请求头过大）会自动去掉 Cookie 重试，直链按 MP4 保存。
  6. B站登录后一般能下到 1080P：B 站 1080P 是音视频分离流，下载时会自动
     合并成一个 MP4（不需要 ffmpeg）；1080P60 / 4K / HDR 这类大会员画质暂不支持。
     红果短剧的完整分集需要登录：点对应平台卡片，在内置窗口登录一次，回来重新解析即可；
     顶部「登录与限制」里点「去登录」打开平台；已登录的平台按钮会变灰点不动；
     解析前如果检测到未登录，也会先弹出对应平台的限制提示；
  7. AcFun 使用 HLS 分片，程序会自动转封装成 MP4，不需要装 ffmpeg；
  8. 解析失败时，可以先进入原平台页面确认能正常播放，
     再复制当前页面链接回来重试。
  下载目录与长视频共用程序安装目录旁的「视频解析下载」文件夹，但短视频按平台名保存，
  短剧单独放在剧名文件夹里，不会和长视频混在一起。


十九、投屏到电视 / 手机 / 平板（1.2.13 新增）
  1. 先解析出一个能播放的视频，点播放区右上角的「投屏」；
  2. 弹窗会自动搜索同一个 Wi-Fi 下的 DLNA 设备（电视、投影、机顶盒、
     带 DLNA 接收的手机），点设备名即可推送到该设备；
  3. 投屏后电脑端会自动暂停，避免两边同时出声。弹窗里可以暂停 / 继续、
     快退 / 快进 10 秒、停止投屏；换集或换清晰度会自动把新画面重新推过去；
  4. 电视没有 DLNA 接收端时，把弹窗下方生成的局域网地址复制到电视 / 手机 /
     平板浏览器里打开，也能直接播；手机需要支持 DLNA 接收，或者直接用浏览器打开；
  5. 电脑和投屏设备必须在同一个 Wi-Fi / 局域网；电脑端不要退出软件、也不要切到
     别的视频，电视是从电脑上的代理拉流，电脑端关掉画面就会停；
  6. Windows 第一次运行如果弹出防火墙提示，请选择「允许」，否则电视访问不到电脑；
  7. 网页解析线路拿不到真实流地址，投屏按钮是灰的；换到内置播放器线路再投屏。
     部分设备不支持 HLS（m3u8），如果投屏黑屏，换一条 MP4 直链线路再试。
