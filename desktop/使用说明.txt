长视频解析 · 使用说明
========================================

一、这是什么
  把爱奇艺、腾讯视频、优酷、芒果TV 的视频页链接粘贴进来，
  选一条解析线路，就能在程序里直接播放。

  程序本身不提供、不存储任何视频内容。解析由互联网上公开的
  第三方接口完成，线路可能随时失效，换一条或自己添加即可。


二、安装
  1. 运行 changshipin-Setup-<版本>.exe，按提示安装；
  2. 程序未做代码签名，SmartScreen 提示时点「更多信息 → 仍要运行」；
  3. 安装完成后桌面/开始菜单会出现「长视频解析」。


三、四个平台快捷入口
  顶部四个卡片使用各平台官方 App 图标：爱奇艺、腾讯视频、优酷、芒果TV。
  - 点卡片：在内置浏览器窗口打开官网，可正常登录会员账号；
  - 卡片右上角「↗」：用系统默认浏览器打开官网；
  - 在内置浏览器里点开任意剧集后，程序会自动把「具体某一集」
    送到主界面解析播放（工具栏「自动解析」默认开启）；
  - 也可以点「解析本集」手动送入主界面，或点「复制本集」复制当前剧集链接；
  - 在首页/搜索页点「复制本集」会提示「请先点开具体某一集」，
    这是为了避免复制成首页链接。


四、找剧（跨平台搜索）
  1. 点右上角「找剧」；
  2. 输入剧名，勾选一个或多个平台；
  3. 点「开始搜索」，程序会分别打开各平台的搜索结果页；
  4. 在任意平台窗口里点开剧集/某一集，程序自动解析并在主界面播放，
     平台窗口可以留着继续换集。

  外站播放链接（比如爱奇艺搜索页里的「腾讯 外站付费播放」）会自动
  切换到对应平台的内置窗口；其他站点也会用带工具栏的内置窗口打开，
  所以每个窗口上方都有「自动解析 / 复制 / 解析本集 / 浏览器」这排按钮。


五、解析播放
  1. 把链接粘贴到输入框（支持直接粘贴分享文案，会自动提取链接）；
  2. 选一条线路（默认自动选上次成功的线路）；
  3. 点「解析播放」或按 Enter；
  4. 解析页加载完成后即可播放。

  链接示例：
    爱奇艺    https://www.iqiyi.com/v_b13ju3xx7s.html?lt=2
    腾讯视频  https://v.qq.com/x/cover/mzc002001w361jz/x4102olnagg.html
    优酷      https://v.youku.com/v_show/id_XNjU3MzkyOTA0NA==.html
    芒果TV    https://www.mgtv.com/b/817372/24769759.html


六、解析失败怎么办
  - 点「换线路」：用下一条线路重新解析；
  - 设置里打开「解析失败自动切换下一条线路」后，程序会按线路
    列表顺序自动重试；
  - 点侧栏「测速」，看哪些线路当前可访问（测速通过不代表一定能播）；
  - 线路全部失效时，用「官网页面（会员登录）」线路：直接打开原片
    页面，登录会员账号后观看，不经过第三方解析；
  - 芒果TV：默认会先走「芒果TV 原生解析」线路。如果提示地区限制，
    需要在观看国内视频的网络环境下使用；VIP 内容请先在芒果内置窗口
    登录会员，再回到主界面解析，原生线路会自动带上登录 Cookie。


七、线路管理（设置 → 解析线路）
  - 侧栏里灰色的是「未启用」，点一下即可启用（启用后出现在下拉框里）；
  - 每条线路可以启用/停用、改名、改地址、删除；
  - 类型：
      网页：地址形如 https://jx.example.com/?url={url}
            程序在内置浏览器里打开解析页，由解析页播放；
      接口：程序请求 {url} 接口，从返回的 JSON/HTML 里自动提取
            m3u8/mp4 地址，再用内置播放器播放；
      直连：不解析，直接打开原视频页面（适合已登录会员）；
      芒果内置：直接调用芒果TV 官方取流接口，仅用于芒果TV，
            国内网络下优先使用，登录芒果会员后可解 VIP。
  - 「在线更新线路」：从 GitHub 上项目的 lines.json 拉取最新
    内置线路（不会覆盖你自建的线路）；
  - 「恢复内置线路」：回到随程序发布时的默认线路；
  - 建议只保留自己验证过能用的线路，并把它排在最前面。


八、全屏
  点播放区右上角「全屏」（或按 F11）：窗口会铺满整个电脑屏幕，
  并隐藏顶部工具栏与侧栏，只留播放画面和一条悬停才显示的控制条。
  按 Esc 或再点「退出全屏」恢复原样。


九、自动更新
  程序启动约 6 秒后自动检查更新，之后每 4 小时一次；
  发现新版本会后台静默下载；下载完成后提示一次「立即重启安装」，
  点它之后会在后台静默覆盖安装，不会弹出安装向导的下一步/目录选择，
  原有配置、登录状态和桌面快捷方式都会保留，装完自动打开新版本。
  更新包放在 GitHub Releases，程序内置多个国内加速源自动切换。
  也可以在「设置 → 更新」里手动检查。


十、数据与日志
  - 配置 / 解析记录：%APPDATA%\长视频解析\config.json
  - 日志：%APPDATA%\长视频解析\logs\desktop.log
  - 菜单「文件」里可以一键打开这两个目录；
  - 卸载程序不会删除配置；需要彻底清理时手动删除上述目录。


十一、快捷键
  Enter            解析当前链接
  F11              全屏 / 退出全屏
  Esc              退出全屏 / 关闭设置窗口
  F5               刷新画面
  Ctrl+Shift+V     粘贴剪贴板链接并解析
  Ctrl+Shift+N     换线路
  Alt+← / Alt+→    内置浏览器前进 / 后退（平台窗口内）
  Ctrl+Enter       平台窗口内解析本集


十二、免责声明
  本程序仅用于学习与个人合法观看。解析线路由第三方提供，其内容、
  可用性与合法性由提供方负责。请遵守各视频平台的用户协议和当地
  法律法规，不要用于传播盗版内容或商业用途。

十三、快捷方式丢了怎么办
  安装/更新后如果桌面快捷方式不见了：
  - 菜单「文件 → 重新创建桌面快捷方式」；
  - 或打开「设置 → 关于」，点「重建桌面快捷方式」；
  - 也可以直接重新运行安装包，选择原来的安装目录覆盖安装。
